如何取得 Bot 使用者名稱與 API Token：
  1. 下載並打開 Telegram App，完成手機號碼註冊。
  2. 搜尋 @BotFather（有官方認證勾勾），點擊開始對話。
  3. 輸入指令 /newbot。
  4. 依提示輸入你的 Bot 顯示名稱（任意），例如「小明的提醒」。
  5. 接著輸入 Bot 使用者名稱，必須是英文並以 bot 結尾，例如 xiaoming_reminder_bot。
  6. BotFather 會回覆一段訊息，裡面有一串 API Token（格式類似 123456:ABC-xxxx），完整複製它。
  7. 回到本頁面，把「使用者名稱」和「API Token」填入下方欄位，按下確認。
